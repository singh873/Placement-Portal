# Placement Portal

## Project Description

This project is a **Placement Portal Web Application** developed using **Python Flask, HTML, and CSS**.
The system helps manage the campus placement process by connecting **students, companies, and administrators** on a single platform.

Students can create profiles and apply for job opportunities, while companies can post job openings. The admin can manage users, job postings, and placement activities.

## Technologies Used

* Python
* Flask
* HTML
* CSS

## Features

* Student registration and login
* Student profile management
* Job posting by companies
* Apply for jobs
* Admin management system

## Project Setup

1. Clone the repository
2. Install required Python packages
3. Run the Flask application

```bash
pip install flask
python app.py
```
